### 🚧 Featured Projects

#### 🔹 Zely — Fintech Backend
A backend engineering project exploring transaction integrity and distributed systems concepts.

- Idempotent transaction processing
- Event-driven architecture with Kafka
- Redis-powered coordination and rate limiting
- Retry handling, dead-letter queues, and failure recovery
- Monitoring and observability with Prometheus and Grafana

#### 🔹 Vestra — Escrow-as-a-Service
An API-first escrow infrastructure project designed around secure transaction workflows.

- Escrow lifecycle and state management
- Multi-tenant API design
- Event-driven processing
- Webhook signing, retries, and delivery tracking

#### 🔹 CineBook — Movie Ticket Booking API
A backend project focused on the challenges of concurrent seat reservations.

- Fastify and PostgreSQL
- TypeScript and Drizzle ORM
- Database transactions and concurrency control
- Preventing double bookings
- Automated API testing
